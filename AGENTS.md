# Workspace Agent Instructions

These instructions apply to every agent working anywhere in this workspace.

- Everything that automatically or interacts with Minecraft in some way should technically be humanly possible to perform on a vanilla Minecraft client
- Do not assume missing requirements, facts, intent, file contents, environment details, or desired behavior. Inspect and verify what can be verified.
- If anything important remains ambiguous or uncertain, ask the user a clear question before making a choice that could materially affect the result. Minor, low-risk details may be handled with an explicitly stated, easily reversible assumption.
- Check work carefully. Run appropriate tests, validation, or static checks when available, and report honestly what was and was not verified.
- When blocked, explain the exact blocker, the safe approaches already attempted, and what information or permission is needed to continue.
