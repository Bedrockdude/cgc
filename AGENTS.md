# CGC Agent Guide

Read this file first before making changes anywhere in this workspace.

## Workspace Layout

- `cgc-1.21.10/`: main mod project. All production code changes should go here unless told otherwise.
- `Example Skyblock mods/`: reference implementations. Treat these as examples to study, not code to edit.

## Working Rules

1. Do not edit files under `Example Skyblock mods/` unless explicitly asked.
2. Prefer patterns already used in the current `cgc-1.21.10` project.
3. When borrowing ideas from example mods, Don't be afraid to copy things exactly You just have to make sure It is for the Correct Type of file And version
4. Keep changes scoped. Do not restructure the whole mod unless requested.
