# cgc

## Features

<details>
<summary><b>Dungeon</b></summary>

- **Auto SS**
- Spec safe auto SS, Recommended To go for about 11.5 seconds in p3sim


- **Auto Puzzles**
- Blaze Works fantastically recommended
- WaterBoard Works well unclear about how spec safe it is (WIP)
- Beams Breaks frequently
- TTT Works but isn't very spec safe and what's the point
- Weirdos Blatant snapping and I can't be bothered to fix it


- **Auto leap**
- Currently only for healer leaps But I will probably add more in the future


- **Leap Counter**
- Allows you to create a node and while you're standing inside of it it will count how many people of what class Leap to you. Example command ".Lc p2 3 M"


</details>

<details>

<summary><b>Player</b></summary>

- **Mask helper**
- It's an semi-auto mask Set the keybind to whatever your equipment bind is And if you hold it down instead of letting go of it after It will switch your mask for you It prioritizes spirit (I may add cow hat later)

</details>

<details>

<summary><b>Render</b></summary>

- **EnderPearlTrajectory**
- Trajectory but only for pearls

</details>

<details>

<summary><b>Other</b></summary>

- **DNYapper**
- If you hover over someone's head in party finder And click the selected keybind It will message that person One of the messages you said in the Messages text field Separate messages with a "|"
