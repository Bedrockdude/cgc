# AI Context Folder

This folder exists to give coding agents stable, human-written context.

## How to use it

- Put project-wide rules in `../AGENTS.md` at the workspace root.
- Put deeper explanations here.
- Keep files short and specific.
- Update these notes when architecture decisions change.

## Suggested maintenance rule

When a feature is added, update:

1. `project-overview.md` if the overall architecture changed.
2. `example-index.md` if a new example mod becomes relevant.
